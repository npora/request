# 请求库展示站

请求库展示站和在线控制台位于 [request.npora.live](https://request.npora.live/#playground)。

展示站页面、Pages Functions、状态 Worker、配置和回归测试由 [npora/online 的 request 目录](https://github.com/npora/online/tree/main/request) 维护。该目录记录构建所用的请求库提交、预览命令及迁移验收方法。

已有 `www.npora.live/#playground` 和 `www.npora.live/api` 仍通过总官网兼容入口访问。新示例使用 `https://request.npora.live/api`。
